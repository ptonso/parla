# parla Template Spec

Related: **Read first** [architecture](architecture.md), [config](config.md). **See also** [cli](cli.md), [docker](docker.md).

## Overview

This spec defines the exact `parla/` layout that `parla init` produces, the artifact folder that `parla init artifact` adds, and the starter files both write.

Each top-level folder holds one kind of material:

| Folder | Holds |
|---|---|
| `artifacts/` | one folder per artifact: its card, its source files and the files generated for it (`references.bib`, rendered tables, the build outputs `<artifact>.pdf`, `<artifact>_diff.pdf`, `<artifact>.png`, the `<artifact>-<code>` pairs of its translations and `BUILD-ERROR.txt`) |
| `sources/` | the inputs that artifacts read: results, figures, tables, hand-authored `.bib` |
| `texmf/` | project styles |
| `export/` | export snapshots |
| `.parla/` | job state (see jobs) and build intermediates |

The starter templates depend only on base LaTeX and the packaged Layer 2: the paper starter uses stock packages, the talk starter is a plain Beamer deck, and the CV starter is plain `article` with `geometry` and `hyperref`. Personal macros are opt-in through `[storage].texmf_home`; `export` copies the `texmf_home` files an artifact loads, and what those load in turn.

## Language

- **Base tree**: what `parla init` creates.
- **Artifact folder**: `parla/artifacts/<name>/`.
- **Entrypoint**: the file the card names, relative to the artifact folder.
- **Starter**: the file `init artifact` writes as the entrypoint, from a template.
- **Stock template**: the starter for a modality when its audience sets none.

## Map

`parla.template` writes the tree and the starters and resolves the storage mode.

## Contracts

### Storage modes

- **Local** (default): `<root>/parla` is a real directory. A pre-existing `parla/` symlink is an error, since it implies an `asset_root` that is not configured.
- **External** (`[storage].asset_root`):
  - The tree is written under `<asset_root>/<project folder name>`. A project in `~/work/paper` maps to `<asset_root>/paper`.
  - `<root>/parla` is a symlink to that directory.
  - `find_root`, `build`, `link` and `export` resolve `parla/parla.toml` through the project root either way.

### Base tree

```
parla/
  parla.toml                        # [project] version = 1
  artifacts/
    <artifact>/
      card.md
      <entrypoint>                  # for example main.tex
      references.bib                # generated by build, latex engine only
      <artifact>.pdf                # published by build; also <artifact>_diff.pdf and, for diagrams, .png
      BUILD-ERROR.txt               # written by a failed build, deleted by the next success
      table/<id>.tex                # rendered tables
  sources/
    bib/                            # hand-authored *.bib, overlaid on the user library
  texmf/
    tex/latex/project/project.sty   # Layer 3 project-local package
    fonts/opentype/project/         # Layer 3 project-local fonts (optional)
  export/                           # export snapshots
  .parla/
    jobs/<id>/                      # job state, created by job start
    build/<artifact>/               # latexmk outdir, full build log, diff work folder
```

`parla init` creates `parla.toml`, `artifacts/`, `sources/bib/`, `texmf/tex/latex/project/project.sty`, `texmf/fonts/opentype/project/` and `export/`. `init artifact` adds one artifact folder.

- **`artifacts/<artifact>/references.bib`** is not written by `init`. `build` generates it ([latex engine](latex-engine.md#bibliography-overlay)).
- **The project-local style package** is always named `project` (`\usepackage{project}`), whatever the project is called. Its placeholder is `\NeedsTeXFormat{LaTeX2e}`, `\ProvidesPackage{project}[2026/01/01 v0.1 project-local package]`, a one-line comment and `\endinput`.
- **Paths in LaTeX** are written relative to `parla/`, as in `\input{artifacts/icra-paper/section/methods}` and `\includegraphics{sources/results/fig.png}`. There is no `\graphicspath`.
- **No per-project `docker/`.** Layer 3 is mounted, not baked ([docker](docker.md#layers)).
- **Sources are links.** Each entry under `sources/` is normally a symlink to a whole folder of the code project, declared in `[links]` ([config](config.md#parlaparlatoml)).

### Artifact folder

`parla init artifact <name> --modality <m> --audience <a>` writes `artifacts/<name>/card.md` ([config](config.md#the-card)) and the starter entrypoint.

The engine's `starter` method ([engines](engines.md#the-engine)) resolves in this order: the `setup` the audience page declares for the modality, then the modality's stock template. A `setup` names a `template`, which is a document class, and the `packages` it loads; the starter is the stock one with that class and those packages. The class must exist in Layer 1 (the image's TeX Live, including `IEEEtran` and `ieeeconf`), Layer 2 (the packaged texmf), Layer 2b (`[storage].texmf_home`) or Layer 3 (the project texmf), or `init artifact` fails naming it.

### Stock templates

| Modality | Starter | Content |
|---|---|---|
| paper | `main.tex` and `section/introduction.tex` | `article` at `a4paper,12pt` with `amsmath`, `graphicx`, `hyperref` and `project`; the body `\input`s the introduction, then `\label{parla:body-end}`, an invisible page anchor that `measure` reads; `\bibliographystyle{ieeetr}` and `\bibliography{artifacts/<name>/references}` |
| cv | `main.tex` and `section/{header,summary,experience,projects,education,skills}.tex` | `article` at `10pt` with `geometry` (`margin=1.6cm`), `hyperref` and `project`; the body `\input`s the six sections in that order, then `\label{parla:body-end}`; no bibliography, so `references.bib` stays empty; `header.tex` holds a centered name and contact placeholder and each other file only its `\section` heading |
| talk | `main.tex` | `beamer` at `aspectratio=169,11pt` with `graphicx`, `adjustbox`, `appendixnumberbeamer` and `project`; empty title, author and date; a references frame with `\bibliographystyle{apalike}` and `\bibliography{artifacts/<name>/references}` |

The starters write their `\input` and `\bibliography` paths with the artifact name filled in, so a fresh artifact compiles.

## Constraints

- `parla init` and `parla init artifact` MUST be idempotent: they add only missing entries and preserve existing files unless `--force`.
- The base tree MUST contain a valid `parla.toml` with `[project] version = 1`.
- Every file a starter `\input`s MUST exist after `init artifact`, so a fresh artifact compiles.
- `init` MUST NOT write README files into the tree.
- `init artifact` MUST fail when the audience page or modality named does not exist, naming it.
- External storage:
  - A pre-existing real `<root>/parla` MUST fail with the expected asset target and manual migration steps. There is no auto-migration.
  - A `parla/` symlink to an unexpected target MUST fail rather than be repointed.
  - An existing target that `<root>/parla` does not link to MUST fail, since another project may share the folder name.
